# Supplementary Raw Experimental Data
This repository contains all supporting raw data, image files, analysis codes and statistical results for the submitted manuscript.

## File Description
### Microplastic raw image compressed packages
1. **微塑料 50μm 10x (X).zip**
Raw microscope images of 50 μm microplastics, captured under 10× objective lens.

2. **微塑料 50μm 20x (X).zip**
Raw microscope images of 50 μm microplastics, captured under 20× objective lens.

3. **微塑料 50μm 5x (X).zip**
Raw microscope images of 50 μm microplastics, captured under 5× objective lens.

4. **微塑料 100 (1).zip, 微塑料 100 (2).zip**
Raw microscopic images of 1 μm microplastics captured under 100× objective lens. The dataset is divided into two compressed files due to file size limitations.

5. **微塑料1微米20.zip**
Raw microscope images of 1 μm microplastics under 20× objective lens.

6. **微塑料1微米50.zip**
Raw microscope images of 1 μm microplastics under 50× objective lens.

7. **微塑料1微米screenshot.zip**
Screenshot records of 1 μm microplastic observation process.

### Code & Result Files
1. **detect.py**
Python program for microplastic identification and image analysis.

2. **results.csv**
Statistical output results of microplastic detection.

3. **粒径.xlsx**
Particle size measurement data spreadsheet of microplastics.

4. **txt.zip**
Text log files generated during image analysis.

> Notes: All data are only for peer review and result reproduction of this manuscript.
